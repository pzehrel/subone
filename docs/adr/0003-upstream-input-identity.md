# 输入方式切换保留上游来源身份

用户于 2026-11-07 确认：上游订阅支持地址、粘贴和文件输入；粘贴与文件归为同一种手动上游，沿用现有订阅解析格式及节点与上游 DoH 的管理规则。

地址与手动内容之间允许互相切换，只有新内容完整解析成功并保存后才切换，保留来源身份和分组引用，节点本地设置按既有匹配规则保留。这样用户调整输入方式时无需重建来源并修复引用；失败时继续保留原来的来源和生效解析结果。

手动上游通过用户再次粘贴或上传内容更新，不跟踪原文件的后续改动；「更新全部」只拉取地址订阅。

完整规格与文件输入边界见 [Issue #30](https://github.com/pzehrel/subone/issues/30)。
